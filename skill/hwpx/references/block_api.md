## 모드 B — 조립 API (hwpx_full)

`Doc()` 에 블록을 쌓아 올리는 진입점. **내부는 모드 A(`render_report.render`)와 같은
엔진**을 부르므로 결과 문서가 같다(같은 입력이면 본문 텍스트도 셀 치수도 일치한다 —
정합성 테스트로 강제).

**빠지는 것** — 엔진에 없는 기능이라 호출하면 그 서식이 빠지고 `[알림]` 으로 알려 준다(글자는 남는다):
`para(bold=·blue=)`·`add_run(bold=·blue=·ref=)` 혼합 서식 · `blank(pt=)` 수동 간격.
그래서 강조는 서식이 아니라 말머리 `(현황)`·각주 `단어*` 로 한다. 표·도해를 코드로
쌓을 일이 아니면 모드 A 를 쓰는 편이 단순하다.

### 공공기관 표준서식 기본값

| 항목 | 기본값 |
|------|--------|
| **본문 폰트** | 휴먼명조, 15pt |
| **제목 폰트** | HY헤드라인M, 23pt (제목상자) / 16pt (섹션, 자동번호) |
| **참고/주석** | 한양중고딕, 13pt |
| **표 셀** | 한양중고딕 13pt, 가운데 — **헤더행만 bold** |
| **줄간격** | 160% |
| **페이지 여백** | 위아래 15mm, 좌우 20mm |
| **정렬** | 양쪽정렬 (JUSTIFY) |

### 항목부호 체계 (앞칸 = 공백 문자, 내어쓰기 자동)

```
level 1: ☐ (앞칸 1) — 휴먼명조 15pt
level 2: ◦ (앞칸 2) — 휴먼명조 15pt
level 3: - (앞칸 3) — 휴먼명조 15pt   (옛 문서 호환 — 새로 쓰지 않는다)
level 4: · (앞칸 4) — 휴먼명조 15pt   (옛 문서 호환 — 새로 쓰지 않는다)
level 5: * (앞칸 4) — 한양중고딕 13pt (참고)
```

- 마커는 정식 기호: `☐`(U+2610)·`◦`(U+25E6). ㅁ/□/ㅇ/○ 유사문자 금지.
- **마커 단락은 반드시 bullet()/note() 로** (para() 에 기호를 직접 치지 않는다).
- 긴 항목이 줄바꿈되면 둘째 줄이 텍스트 시작점에 자동 정렬(내어쓰기).

### 번호 항목체계

```
Ⅰ., Ⅱ., Ⅲ. → 1., 2., 3. → 1), 2), 3) → (1), (2), (3) → ①, ②, ③
```

### 날짜·시간 표기

- 날짜: `'26. 4. 7` 형식 / 시간: `15:20` 형식 (24시)

### 사용법 (권장 — body 한 방, 모드 A 와 동일 입력 형식)

```python
import sys, os
SKILL_DIR = "<스킬 폴더 경로>"
sys.path.insert(0, os.path.join(SKILL_DIR, "scripts"))
from hwpx_full import Doc

doc = Doc("○○ 추진계획(안)")             # 제목상자 23pt + 【주관】 블록 자동

doc.body("\n".join([                      # 기호만 쓰면 간격·앞칸·내어쓰기 자동
    "1. 추진배경",                        # 단 헤딩 (자동번호 16pt)
    "□ (근거) 관련 규정에 따른 추진 필요",
    "◦ (현황) 현행 체계의 한계",
    "* 참고: 관련 자료 출처",
    "2. 주요내용",
    "□ (실태) 현행 처리 방식",
    "3. 추진방안",
    "□ (방안) 핵심 추진 내용",
    "4. 향후계획",
    "◦ ’26.  9.	: 착수",
]))

tbl = doc.table(3, 3).col_ratios([1, 4, 2])   # 표준서식 표 (13pt 중고딕 B·가운데·이중선)
tbl.cell(0, 0, "단계").cell(0, 1, "내용").cell(0, 2, "일정")
tbl.cell(1, 0, "1").cell(1, 1, "시범").cell(1, 2, "'26.상")
tbl.cell(2, 0, "2").cell(2, 1, "확산").cell(2, 2, "'26.하")

doc.image_placeholder(["구성도"])          # <이미지 삽입> 자리+캡션 (1~3칸)

os.makedirs("output", exist_ok=True)
doc.save("output/보고서.hwpx")            # mimetype 규격 보장
```

### API 레퍼런스 (모드 B)

| 메서드 | 설명 |
|--------|------|
| `Doc(title)` | 문서 생성 — 제목상자(23pt)·【주관】 블록은 템플릿 내장 |
| `doc.body(text)` | **권장.** 여러 줄 본문 — 줄 첫 기호로 단위 판정, 간격 자동 |
| `doc.heading(text)` | 섹션 헤딩 (16pt, 자동번호 — 입력의 수동 번호는 제거됨) |
| `doc.bullet(text, level=1, marker=None)` | 항목부호 (기호+앞칸+내어쓰기 자동) |
| `doc.note(text)` | 참고(`␣␣␣␣* `) 13pt 한양중고딕 |
| `doc.para(text="")` | 기호 없는 본문 단락. Para 반환 — `bold=`·`blue=` 는 서식만 빠지고 `[알림]` |
| `doc.table(rows, cols)` | 표준서식 표. Table 반환 |
| `tbl.col_ratios([1, 4, 2])` | 열 너비 비율(열 수만큼). 전체 폭은 고정 |
| `doc.diagram(rows, cols)` | 도해용 모눈 표(= `table(...).as_grid()`). Table 반환 |
| `tbl.row_heights([7, 2, 7])` | 행 높이(mm, 행 수만큼) |
| `doc.image_placeholder(["캡션", …])` | `<이미지 삽입>` 자리+캡션 (1~3칸) |
| `doc.blank(pt=5)` | 수동 간격 — 엔진에 없어 빠지고 `[알림]`(간격은 자동) |
| `doc.save(path)` | HWPX 저장 (mimetype 규격 보장). 절대경로 반환 |

`Para.add_run(text)` — 런 이어 붙이기. `bold=`·`blue=`·`ref=` 는 서식만 빠지고(글자는 본문체로 남는다) `[알림]`.
`CellFmt(bold=, align=, borders=, bg=)` — 표 셀 기본: 헤더행 bold·데이터행 일반,
모두 가운데. `bold=True` 로 데이터 셀 볼드 강제, `align="LEFT"` 로 정렬 변경,
`borders={"all":"NONE","top":"SOLID 0.3"}` 와 `bg="#E1EAF6"` 로 도해용 선·배경.
모드 A 의 `cells=[{"r":…,"c":…}]` 와 **같은 엔진으로 간다** — 두 모드가 같은 표를 낸다.
간격 규칙(자동): 헤딩 앞 8pt · 헤딩 뒤 5pt · ☐ 사이 5pt · ☐→◦/-/* 3pt (skeleton 과 동일).
