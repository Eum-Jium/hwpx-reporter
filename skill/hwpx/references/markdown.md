### 마크다운 → 개조식 변환 규칙

`hwpx_core.mdconv` 가 정하는 대응이다. **번역기지 편집기가 아니다** —
내용을 고르거나 줄이지 않는다.

| 마크다운 | 개조식 |
|---|---|
| `## N. 제목` | `N. 제목` (번호가 없으면 순번을 매긴다) |
| `- 항목` | 들여쓰기 **0 = □** · **2 = ◦** · **4 이상 = -** |
| `> 참고` | `* 참고` — 각주·비고·그림 캡션이 다 이 줄이다 |
| 마크다운 표 | `[표N]` 마커만 본문에 남고 표는 `tables=` 로 빠진다 |
| `[이미지N]` | 순번을 **다시 매긴다**(단마다 1 로 겹쳐 와도 된다) |
| `'26. 9월<공백>내용` | 날짜와 내용 사이가 탭이 되어 열이 맞는다 |
