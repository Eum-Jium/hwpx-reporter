### tables / images

- `tables=[{"headers": [...], "rows": [[...], ...]}, ...]` — 양식 내장 그리드를
  복제해 문서 끝에 추가 (헤더 하단 이중선 등 정식 표 모양).
- **열 너비** — `"col_ratios": [1, 4, 2]` (열 수만큼). 표 **전체 폭은 고정**이고
  그 안에서만 비율대로 나뉜다 — 같은 문서의 표들이 좌우로 어긋나지 않게 하기
  위해서다. 생략하면 정본 배분(첫 열 고정 + 나머지 균등). 한 글자도 못 담을
  만큼 좁아지는 비율은 거부하고 기본 배분으로 돌아간다(사유는 `warnings`).
- **셀 병합** — `"merges": [{"r1": 0, "c1": 1, "r2": 0, "c2": 2}, …]`.
  (r1,c1)=좌상단, (r2,c2)=우하단이고 **둘 다 포함**이다. 행은 헤더행 포함 0 부터.
  덮인 칸의 글자는 버려지므로 **앵커 칸에 적는다**(버리면 `warnings` 로 알린다).
  겹치는 병합·범위 밖 병합은 그 항목만 무시한다.
- **셀 서식** — `"cells": [{"r": 1, "c": 2, "align": "LEFT", "bold": true}, …]`.
  행은 **헤더행 포함 0 부터**. `align` 은 LEFT·CENTER·RIGHT·JUSTIFY,
  `bold` 는 주지 않으면 정본 규칙(헤더행만 볼드) 그대로다.
- **칸 테두리·배경** — 같은 `cells` 항목에 얹는다.
  `{"r":1,"c":0,"borders":{"all":"NONE","top":"SOLID 0.3"},"bg":"#E1EAF6"}`
  · 변 이름은 `left·right·top·bottom·all`. `all` 을 먼저 깔고 개별 변이 덮는다.
  · 값은 `'종류 [굵기mm] [#색]'`(순서 무관) 또는
    `{"type":…,"width":…,"color":…}`. 종류는 **NONE·SOLID·DASH·DOUBLE_SLIM**
    넷뿐이다 — 정본과 양식에서 실제로 쓰이는 것만 받는다. 다른 값은 무시하고 알린다.
  · `bg` 는 `#RRGGBB`, 빈 문자열이면 배경을 지운다.
- **칸 글자** — `{"r":1,"c":2,"text":"값"}` 으로 그 칸의 글자를 덮는다.
- **행 높이** — `"row_heights": [7, 2, 7]` (mm, 행 수만큼). 생략하면 종전 고정 높이.
  연결선만 있는 행을 얇게 두는 데 쓴다.
  · 정렬을 바꾸는 자리는 정해져 있다 — 글자가 긴 열(비고·조치사항)만 `LEFT` 로
    돌린다. 짧은 라벨 열을 왼쪽으로 돌리면 정본과 어긋나 보인다.
  · 범위 밖 셀·모르는 정렬값은 그 항목만 무시하고 `warnings` 로 알린다.
- **셀 글자 수 한계(13pt 기준)**: 첫 열은 **7자**, 나머지 열은 **13자**를 넘으면
  셀 안에서 두 줄로 접혀 행 높이가 들쭉날쭉해진다. 라벨을 줄여 맞춘다
  (`창구 집중 시간대`→`집중 시간대`, `실무협의회 개최·우선순위 확정`→`협의회 개최·순위 확정`).
- `images=[{"captions": ["...", ...]}, ...]` — 이미지자리(칸 1~3개, `count` 로 캡션
  없이 칸 수만 지정 가능). 단수 `caption` 오기(誤記)도 허용되지만 정식은 복수형.
  - **실물 그림**은 `path`(파일 경로) 또는 `b64` 로 준다. 칸이 여럿이면
    `"sources": [{"path": …}, {"b64": …}]` 로 칸마다 하나씩.
    `height_mm`·`width_mm` 로 표시 크기 상한(비율 유지). 안 주면 종전대로
    `<이미지 삽입>` 자리표만 그린다.
  - 그림 바이트는 `BinData/` 에 임베드되고 `content.hpf` 에 등록된다. 같은 그림을
    여러 칸에 써도 파일은 하나만 들어간다. 못 넣으면 자리표로 두고 사유를 남긴다.
  - **칸 높이가 그림에 맞춰 줄어든다** — 자리표는 202.5pt 를 먹지만 20mm 그림은
    62.3pt 다(실측). 분량 판정은 `hwpx_core.volume.image_slot_pt()` 가 안다.
- **본문(body) 없이 tables/images 만 요청하면 실패를 반환**한다 — 정상 동작.
